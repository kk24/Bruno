# Bruno API Collections
A personal workspace for learning and experimenting with the Bruno API Client.
This repository stores my Bruno collections, environment files, and any custom scripts I create while exploring API workflows.

# Repository Structure
/collections — Bruno collections for different APIs I’m testing or learning
/environments — Environment variables for local, dev, or test setups
/scripts — Helper scripts for automation, testing, or data generation
README.md — You’re reading it

# Purpose
This repo helps me:
- Practice using the Bruno API Tool
- Organize API requests into reusable collections
- Track my learning progress
- Store scripts that support API testing or automation
- Version-control my API experiments

# Getting Started
Install Bruno from the official site
Clone this repository
Open the repo folder directly in Bruno
Start exploring or adding new collections

# Notes
This is a learning-focused repository. Expect experiments, drafts, and evolving structure as I get more comfortable with Bruno.
